# Pokémon Prediction

Project for predicting the outcome of Pokémon battles. It processes battle data, extracts information about teams and battle progression, and uses an XGBoost model to predict whether the player won.

## Project Structure

- `src/`: code for reconstructing battle states, extracting features, training the model, and generating predictions
- `data/raw/`: contains the dataset 
- `models/`: contains the trained model
- `submissions/`: contains the output of the predictions in a csv file
